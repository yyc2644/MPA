# MPA

MPA 面向 Pokemon TCG Pocket 的日常自动化，目标是把免费卡包、得卡挑战、礼物箱、任务奖励、商店免费项、对战和社交流程逐步沉淀成可维护的 MaaFramework pipeline。

## 使用边界

- 不保存、输入或管理第三方账号密码、验证码。
- 不提供账号切换或账号绑定自动化；请用户自行完成模拟器内登录。
- 不自动确认付费购买。
- 不默认自动打真人排位。
- 对送卡、交换卡牌等操作需要白名单和确认策略。

## 前端

本项目通过 `interface.json` 接入 MFAAvalonia。MFAAvalonia 会读取任务、资源、控制器、多语言和文档配置，并生成通用图形界面。
