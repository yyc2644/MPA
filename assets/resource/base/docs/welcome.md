# 欢迎使用 MPA

MPA 是一个基于 MaaFramework 和 MFAAvalonia 的 Pokemon TCG Pocket 自动化项目。

当前前端开放“启动并回到主页”“打开免费卡包”“得卡挑战”和“关闭游戏”。每日流程、领取礼物、商店免费项、任务奖励、对战、送卡和交易仍在开发中，已从任务列表隐藏，玩家无法勾选或执行。

Maa Project Interface v2 没有禁用任务字段，因此开发中功能采用“隐藏入口”的方式保护；只有完成截图适配、异常分支和模拟器回放验证后才会逐项开放。本项目假设用户已经自行完成模拟器内的账号登录；账号密码、验证码、授权确认、付费购买和不可逆交易操作不会自动执行。
