# 自动抽卡

自动抽卡用于打开选定扩充包中当前已经储存的所有免费卡包。流程识别卡包能量条中的“可用卡包”图标，而不是只判断 `MAX`：即使第二包仍在倒计时，只要已经存有 1 包也会继续抽取。

在前端展开任务配置后，可以从“目标扩充包”中选择要打开的卡包，默认值为 `B3b · 奇迹日常`。

当前共配置 19 个正式扩充包：A 系列 11 个（A1 至 A4b）和 B 系列 8 个（B1 至 B3b）。PROMO 活动卡包不属于常规开包入口，因此不提供选择。

流水线会按配置切换 A/B 系列、识别对应扩充包名称，并在进入卡包后用扩充包编号进行二次确认。旧扩充包不在首屏时会自动向下滚动查找。

撕包阶段会沿卡包封口从右向左完整划过；失败时使用不同高度和速度最多重试两次。流程只在识别到快进、卡牌登记、继续、跳过或 OK 等开包后状态时继续，不再仅凭“开封”提示消失就提前结束。三次均未进入开包后状态则停止当前任务，避免误触。

每次返回扩充包详情页后都会重新识别顶部的可用卡包图标；仍有卡包就继续打开，图标消失后立即结束。流程不会使用卡包沙漏或宝可金币补充次数。

本次已在繁体中文、720×1280 模拟器中完成 B3b 免费卡包实测，并已在 MFAAvalonia 任务列表开放。其他语言、A 系列和部分异常弹窗尚未完成实机回放验证。
