# 得卡挑战

该任务会先领取当前列表顶部所有 `Free` 免费挑战，再按所选策略持续完成普通得卡挑战，直到没有可用体力或没有可选的 1 点卡组。当前已在繁体中文、720×1280 的 Android 画面完成实机流程标定。

## 策略

- **高稀有度优先**：寻找界面显示消耗 3 或 4 点体力的卡组，作为包含一星及以上卡牌的稳定判断依据。
- **低稀有度优先**：只选择消耗 1 点体力的卡组，用于获取 ♦1 / ♦2 卡牌。
- **指定卡牌**：对五张卡的卡名区域进行 OCR，只进入命中玩家配置名称的卡组；多个名称使用 `|` 分隔。

策略只决定进入哪一组五张卡。洗牌后的卡牌位置不可可靠预测，因此任务固定选择上排中间位置，不提供“追踪洗牌”功能。

高稀有度和指定卡牌策略会优先寻找配置目标；若目标已经找不到或剩余体力不足以支付高消耗组，任务会回到列表顶部，用 1 点卡组尽量清空剩余体力。低稀有度策略会直接循环选择 1 点卡组。

## 消费保护

免费挑战会在详情页再次确认 `Free` 或 0 消耗，避免列表刷新后误点普通挑战。免费结果处理完毕后，任务返回列表继续寻找免费项；全部领完才执行所选策略。

普通挑战只在详情页的蓝色可用 `OK` 按钮被确认时继续；体力不足时按钮为禁用状态，任务会关闭详情页并停止。不会进入得卡沙漏或宝可金币确认流程。

## 结果记录

“保存获得卡牌截图”默认开启。获得卡牌的大图出现后，截图会保存到：

```text
records/wonder_pick/YYYY-MM-DD/wonder-pick-HHMMSS.mmm.png
```

关闭该选项后仍会完成挑战，但不会写入结果图片。截图助手是发布包内自带的原生小程序，不需要玩家安装 Python。

## 当前限制

- ROI 按 720×1280 竖屏界面标定。
- 指定卡牌依赖当前游戏语言的 OCR，请输入游戏画面实际显示的卡名。
- 低稀有度策略目前只按 1 点体力筛选，尚未根据“未拥有”或“少于两张”进一步排序。
- 每次任务会领取所有已显示的免费挑战，并循环普通挑战；目标与 1 点兜底搜索都有明确的滚动次数上限。
